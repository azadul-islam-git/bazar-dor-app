# 🛍️ Bazar Dor

**Live Website:** https://bazar-dor-app-weld.vercel.app/

Bazar Dor is a modern online product price browsing platform built to help users explore products and view their prices with ease. It features a clean, responsive interface and user authentication, making it simple for users to create an account and access product pricing details.

## 🛠️ Technologies Used

- **Next.js** — React framework for building the application.
- **React** — Component-based user interface development.
- **TypeScript** — Type safety and improved developer experience.
- **Tailwind CSS** — Utility-first styling.
- **DaisyUI** — Prebuilt UI components and styling utilities.
- **Better Auth** — User authentication and session management.
- **React Icons** — Icons for navigation and interface elements.
- **React Hot Toast** — Toast notifications for success and error feedback.
- **Bazar Dor API** — Product data and pricing information.

## ✨ Features

- **Product Browsing:** Explore products fetched from the Bazar Dor API.
- **Price Information:** View product prices and related details.
- **User Authentication:** Sign up and sign in securely using Better Auth.
- **Google Profile Integration:** Sign in with Google and display the user's profile image when available.
- **Profile Management:** View and update profile information.
- **Form Validation:** Validate required fields and ensure passwords match during registration.
- **Toast Notifications:** Display success and error messages for user actions.
- **Responsive Design:** Enjoy a consistent experience across mobile, tablet, and desktop devices.
- **Bengali Interface:** Provide a user-friendly experience with Bengali text throughout the interface.
